# DataLab Vendas

Projeto Integrador da disciplina Desenvolvimento Front-end para Web.

O DataLab Vendas é um mini-painel de análise de dados de uma loja de periféricos de informática.
Ele apresenta dados de vendas em tabela, gráfico animado e vídeo, e traz um analisador em JavaScript
que classifica cada produto (alta saída, baixa saída ou sem vendas) e resume os resultados.
O objetivo é mostrar, de forma simples e acessível, como transformar números soltos em informação útil.
